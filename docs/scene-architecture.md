# 清明南宋游戏场景架构

更新：2026-11-19

## 1. 原画空间结构

以张择端《清明上河图》原卷的空间叙事为布局参考。原作是北宋汴京风俗画；本项目采用其场景组织方式，表现南宋市井生活，不将北宋原画误称为南宋作品。

地图按长卷展开，沿 X 轴由郊野进入城市：
1. 郊野段：田地、疏落村舍、树木和进城道路。
2. 汴河段：河道、虹桥、桥头道路、漕船、码头、临水店铺。
3. 城市段：沿街商铺、摊位、后巷、院墙与城门。人流和建筑密度由郊野向城内逐步增加。

这不是平均对称的河岸布景。市场主要集中在北岸，南岸保留较疏朗的道路、树木和临水空间；虹桥是交通视觉中心，码头与船只形成水运活动区。

## 2. 当前地图坐标

- Three.js 0.179.1，Y-up。
- 汴河沿 X 轴延伸，河道宽约 12 个世界单位，与虹桥约 13.3 米的跨河方向匹配。
- 虹桥横跨河道，主桥中心约为 [0, 0, 0]。
- 郊野在 X=-80 左右；桥头与码头在中段；城市街市和城门在 X=20 至 82。
- 地面、河岸、桥头道路、北岸主街、柳树、田块、摊位和城门由 `src/world.js` 构建。
- 地点与人物/交通资产位置由 `src/world-layout.js` 管理。

## 3. 22个GLB资产

### 首批6个地标
- 虹桥、石拱桥、码头、茶馆、酒楼、江边大商楼。
- 位置写在 `public/assets/manifest.json`。
- 第一批6个模型的缩放已经烘焙进几何，运行时 scale 固定为 1。

### 新增16个资产
- 角色：商人、摊贩、船夫、挑夫、店员、茶馆伙计、工匠、文人。
- 船：货船、客船、蓬船、小船、渡船。
- 交通：手推车、货车、轿子。
- 每个模型的实测包围盒、逐模型 scale 和推荐朝向写在 `public/assets/3d/asset-catalog-batch2.json`。
- 16个模型原点在几何中心，加载后按包围盒下沿贴地。
- 角色模型没有骨骼动画，当前作为场景人物布置；后续需要另做绑定/动作，不能用整体漂移冒充走路动画。

## 4. 加载与渲染

- 入口：`index.html` → `scene.js`。
- 环境：`src/world.js`。
- 地图坐标和实体布置：`src/world-layout.js`。
- 资产加载：`src/asset-manager.js`。
- 所有GLB使用同一个配置了DRACOLoader的GLTFLoader。
- 首批6个从资产CDN载入；新增16个从Pages项目中的 `public/assets/3d/` 载入。
- 5艘船沿汴河缓慢往返；人物模型没有骨骼，当前作为静态NPC，可点击交谈。
- 街市摊位可点击买卖，钱袋和行囊暂存在当前设备的 localStorage；这是单机交易原型，还不是多人共享经济。
- HUD提供郊野、虹桥、街市、全景四个快速视角；鼠标/触屏拖动旋转，WASD平移。
- Pages项目：`qingming-riverside`，GitHub main自动部署。
